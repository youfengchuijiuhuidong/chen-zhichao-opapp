## 二、 五大核心审计维度横向深度剖析

### 2.1 【数学严谨性与符号系统】KaTeX 公式与定义严密性

1. **$\tau$ 符号双重载灾难（式 2-15）**：
   - 在算子 `mirror_descent` 中，论文原文式 (2-15) 写作：
     $$z_{\tau+1} = \nabla\Psi^*\big(\nabla\Psi(z_\tau) - \tau \nabla F(z_\tau)\big)$$
     此处作者将步长记作 $\tau$，但迭代轮次下标同时也是 $\tau$！导致读者在阅读时极易误解为“第 $\tau$ 步的步长随着迭代轮次线性增长”或产生因果混淆。
   - 而在其后续展开算子 `mirror_descent_three_steps` 中，作者又将步长悄然换成了 $\eta$：
     $$\zeta_{\tau+1} = \zeta_\tau - \eta \nabla F(z_\tau)$$
   - **审计修正建议**：在 KaTeX 与元数据中明确规范，将式 (2-15) 记为 $z_{\tau+1} = \nabla\Psi^*\big(\nabla\Psi(z_\tau) - \eta_\tau \nabla F(z_\tau)\big)$，并在 `note` 中加入符号澄清说明。

2. **OCR 乱码与格式残损**：
   - 算子 `kl_divergence` 的 excerpt 字段中存在：`其中 DKL [Q(z)kP(z|x)] 为分布 Q(z) 和分布 P(z|x) 之间的库尔贝克-莱布勒散度`。其中 `k` 是 LaTeX 命令 `\Vert` 或 `\|\|` 被 OCR 引擎误判导致的典型工程乱码，严重损害学术严谨性。
   - 应修正为 $D_{\mathrm{KL}}[Q(z) \,\Vert\, P(z|x)]$。

3. **变分下界与期望符号书写**：
   - 算子 `elbo` 中，KaTeX 定义为 $\mathbb{E}_{Q(z)}[\log(p_\theta(x\mid z)P(z)/Q(z))]$，但部分关联文档使用了非标准的 $E_Q$。应统一使用 $\mathbb{E}_{z \sim Q}[\dots]$，并明确标出联合概率 $p_\theta(x, z) = p_\theta(x\mid z)P(z)$。

### 2.3 【Canvas 动画与分镜对照】机理保真、分镜四拍与滑块因果链

#### 2.3.1 核心缺陷一：张冠李戴 —— `wasserstein_space_p2` 概念移位
- **问题溯源**：
  在 `source_app/js_anim_ch2.js` 的 `wasserstein_space_p2` 实现中：
  ```javascript
  const sep = sl(S, "sep", 1);
  S.sim.z.forEach((p) => glow(ctx, cx + p.x * sc * sep, cy - p.y * sc * sep, 4, T.c2));
  S.metrics["搬迁"] = sep;
  ```
  滑块标签为 **“搬迁距离”**（`sep`），仪表盘显示 `搬迁 = sep`。
- **数学谬误剖析**：
  算子定义的是**沃瑟斯坦空间本身** $\mathcal{P}_2(\mathcal{D}) = \{Q \in \mathcal{P}(\mathcal{D}) \mid \int \|z\|^2 dQ < \infty\}$，这是一个以“概率分布”为点的无穷维黎曼-奥托（Otto）流形！
  但当前动画却把一个单分布粒子云沿原点径向拉伸（改变二阶矩），却标注为“搬迁距离”。
  **“搬迁”是两个分布之间的 $W_2$ 测度传输（对应算子 28 `w2_distance` 或算子 23 `transport_map`），而不是单个空间本身的几何属性！**
- **重构方案**：
  应当在画布上展示“空间内的点是分布”这一核心抽象层级：
  - 画布左侧/全景：绘制一个弯曲的抽象流形 $\mathcal{P}_2$，流形上的每一个点代表一个概率测度 $Q_1, Q_2, \dots$；
  - 局部探针：点击或选中流形上的某个点，弹出该点对应的真实粒子分布直方图，并由仪表盘检测 $\sum w_i = 1$ 与二阶矩 $\mathbb{E}[\|z\|^2] < \infty$ 是否满足“入场券”。

#### 2.3.2 核心缺陷二：动绘脱节 —— Tick 数值仿真被 Draw 强制覆盖
- **问题溯源**：
  在 `variational_inference` 中：
  `tick` 函数进行了真正的有限差分梯度下降：
  ```javascript
  const dmu = (quadKL(S.sim.mu + h, S.sim.sig, pfn, ...) - kl0) / h;
  S.sim.mu -= dt * 1.8 * rate * dmu;
  ```
  然而在 `draw` 函数中，作者却用静态滑块插值直接覆盖了 `mu`：
  ```javascript
  const t = n01(S, "rate", 0.8, 0.2, 2.2);
  if (S.phase === 2) { mu = lerp(-1.85, 0.08, t); sig = lerp(0.4, 0.72, t); }
  ```
- **严重后果**：
  1. 用户在暂停状态下拉动滑块，高斯曲线瞬移，毫无动力学平滑演化感；
  2. 右上角的 KL 历史折线图（Sparkline）由 `tick` 驱动，而画布中心的高斯曲线由 `draw` 中的 `t` 强制指定，导致曲线显示的位置与折线图上的 KL 真实数值**完全不对应**！
- **修复方案**：
  `draw` 必须严格消费 `S.sim.mu` 与 `S.sim.sig`，滑块 `rate` 仅作为 `tick` 中 ODE 的积分步长增益参数。

#### 2.3.3 核心缺陷三：滑块语义不符 —— `latent_max_likelihood`
- 滑块 key 设为 `beta`，标签写作“变分贴合”，但该算子是纯经典极大似然，根本尚未引入变分分布 $Q$！
- 内部代码实际控制的是 Monte Carlo 采样数：`nMC = Math.max(3, Math.round(3 + beta * 28))`。
- **修复方案**：滑块 key 统一更为 `samples` 或 `n_mc`，标签更为“蒙特卡洛积分点数”，数值范围设为 $4 \sim 64$。

### 3.1 算子 `latent_marginalization` —— 隐变量边缘化 (latent-variable marginalization)

- **章节出处**：`§2.1.1 (2-1)`
- **拓扑结构**：入度 **0**，出度 **1**
  - **上游节点**：_无（根节点或定义起点）_
  - **下游节点**：`latent_max_likelihood` (Ch2: 隐变量极大似然目标)

#### (1) 数学严谨性与符号自洽审查
- **KaTeX 表达式**：
  $$
  P(x)=\int_{\Omega} P(x\mid z)\,P(z)\,dz
  $$
- **数学定义**：`P(x)=∫_Ω P(x|z)P(z) dz  (2-1)`
- **学术审查评语**：公式 $P(x)=\int_{\Omega} P(x\mid z)P(z)\,dz$ 严谨。注意 $\Omega$ 应明确指代隐空间流形域 $\mathbb{R}^{D_{\mathrm{LV}}}$。

#### (2) 物理直觉与教学穿透力评估
